>[!NOTE] Определение
>**Система сборки** (*англ. build system*) — программный инструмент, который по текстовому описанию проекта автоматически запускает компилятор, ассемблер и компоновщик в нужном порядке и с нужными параметрами, формируя из исходного кода готовый исполняемый файл прошивки.
