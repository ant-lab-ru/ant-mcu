>[!NOTE] Определение
>**I²C** (*англ. Inter-Integrated Circuit*) — стандарт синхронной последовательной связи между микросхемами по топологии ведущий–ведомый на двухпроводной шине, разработанный Philips: задаёт правила обмена, при которых по общим линиям допускается несколько ведомых устройств, различаемых адресом на шине.
