>[!NOTE] Определение
>**RS-232** (*англ. EIA-232*) — стандарт физического интерфейса для последовательной полнодуплексной связи по схеме точка–точка: кодирует биты однополярным напряжением (плюс — логический «0», минус — логическая «1»), для работы с 3,3-вольтовыми микроконтроллерами требует внешней микросхемы-трансивера.
