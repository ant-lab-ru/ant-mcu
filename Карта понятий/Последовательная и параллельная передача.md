>[!NOTE] Определение
>**Последовательная и параллельная передача** (*англ. serial / parallel transmission*) — классификация организации линий данных: при **параллельной** типично несколько линий данных несут биты одной машинной порции в один такт шины; при **последовательной** порция передаётся **бит за битом** во времени по ограниченному числу линий (часто одной линии данных наряду с тактом, управлением и т. п.).
