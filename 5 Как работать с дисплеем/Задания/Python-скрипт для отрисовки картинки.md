# Инструкция

1. Создать скрипт `disp_image.py`  в папке проекта `05-display`

2. В скрипте подключить библиотеку для работы с изображениями

``` Python
from PIL import Image
```

3. Прочитать файл изображения и получить его размеры

``` Python
image = Image.open('5 Как работать с дисплеем/Задания/pics/get.jpg')
width, height = image.size
```

4. Открыть Serial-порт и передать картинку по одному пикселю командой `disp_px`  из API

5. В блоке `finally` сделать паузу 0.1 перед закрытием порта, чтобы данные о последних пикселях успели передаться

6. Запустить скрипт и увидеть изображение на дисплее
