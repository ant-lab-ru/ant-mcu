# Инструкция

1. Добавить в `main.c` включение заголовочного файла `ili9341-display.h` для доступа к высокоуровневым функциям рисования на экране

> [!NOTE] Примечание
> 
> В предоставляемой библиотеке для рисования на экране доступны следующие функции:
> ``` С
> ili9341_fill_screen()
> ili9341_draw_pixel()
> ili9341_draw_filled_rect()
> ili9341_draw_rect()
> ili9341_draw_line()
> ili9341_draw_text()
> ```
> 
> В этом задании мы воспользуемся только функцией `ili9341_fill_screen()`.

2. Добавить в API команду `disp_screen` с колбэком `disp_screen_callback`

3. Реализовать функцию `disp_screen_callback()`

``` C
void disp_screen_callback(const char* args)
{
	uint32_t c = 0;
	int result = sscanf(args, "%x", &c);
	
	uint16_t color = COLOR_BLACK;
	
	if (result == 1)
	{
		color = RGB888_2_RGB565(c);
	}
	
	ili9341_fill_screen(&ili9341_display, color);
}
```

> [!NOTE] Примечание
> 
> Функция `sscanf()` возвращает количество аргументов, которое ей удалось прочитать из строки. Это позволит нам сделать команду, которая работает с разным количеством аргументов:
> - Если пользователь вызовет команду `disp_screen` без аргументов, прошивка закрасит экран цветом по умолчанию (например, чёрным)
> - Если пользователь вызовет команду `disp_screen` с одним аргументом в виде 16-ричного числа, прошивка закрасит экран указанным цветом

> [!NOTE] Примечание
> 
> Микросхема ILI9341 оперирует цветовой моделью **RGB565** в которой цвет храниться в 16 битах информации (двух байтах) со следующим распределением:
> - 5 бит на красный
> - 6 бит на зелёный
> - 5 бит на синий
> 
> Это удобно в микроконтролерах для экономии памяти и ускорения общения с дисплеем по SPI.
> 
> Однако, переводить цвета «в голове» при такой модели довольно сложно. Поэтому пользовательский интерфейс к дисплею мы сделаем в цветовой модели **RGB888**, в которой на каждый цвет приходится ровно один байт. Цвета в таком формате удобно воспринимать и задавать 16-ричными числам, потому что на каждый цвет приходится ровно две цифры, расположенные в фиксированной части числа.
> 
> Например:
> - `0x000000` -> (0, 0, 0) -> чёрный
> - `0xFFFFFF` -> (255, 255, 255) -> белый
> - `0xFF0000` -> (255, 0, 0) -> красный (red, **R**)
> - `0x00FF00` -> (0, 255, 0) -> зелёный (green, **G**)
> - `0x0000FF` -> (0, 0, 255) -> синий (blue, **B**)
> - `0xFF00FF` -> (255, 0, 255) -> пурпурный (magenta)
> - `0xFFFFFF` -> (255, 255, 0) -> жёлтый (yellow)
> 
> В библиотеке дисплея реализован макрос `RGB888_2_RGB565` для перевода кода цвета из **RGB888** в **RGB565**.
