# Задания

1. Создать проект прошивки портативного измерителя состояния атмосферы с названием `06-deivce`
2. Реализовать интерфейс управления через COM‑порт, с обязательными командами `version` и `help`
3. Обеспечить работу прошивки с датчиком BME280
4. Обеспечить работу прошивки с дисплеем ILI9341
5. Реализовать логику измерений с регулируемым периодом измерения
6. Разработать базовый GUI прибора с выводом результатов измерений в виде текста
7. Придумать и добавить в GUI прибора визуализацию измерений через столбцы, стрелки, цвета и т.д.
8. Добавить в GUI прибора построение графиков измерений за последние 60 секунд
9. Запустить прибор с питанием от аккумулятора
10. Запушить исходники прошивки на GitHub
