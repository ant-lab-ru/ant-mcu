# Цель

Познакомить студентов с основными типами периферийных модулей внутри микроконтроллера и подходами по работе с ними

# Задачи

Определить место периферии внутри микроконтроллера.

Познакомиться с концепцией Memory-mapped IO. Регистры периферии. Регистры процессора.

Системная шина памяти и как происходит обращение по адресам внутри микроконтроллера.

Познакомиться с периферией на примере АЦП.

Научиться читать документацию периферии в даташите.

Коммуникационная периферия: SPI, I2C, UART

Периферия памяти: блоки внутренней памяти, блоки внешней памяти, DMA.

# Наброски

1. Внутренняя периферия
	1. АЦП (акцент на работе с периферией через регистры, работа с потенциометром)
	2. Таймеры (ШИМ на встроенный светодиод)
	3. DMA (микрофон, двойная буферизация, скрипт, который скачивает WAV-файлы, которые сразу можно послушать)
	4. Отладка (специальные малинки в корпусе)
	5. Прерывания (фундаментальный рассказ про SP, PC, регистры процессора)
