# Цель

Познакомить студентов с основными понятиями в части встраиваемых систем и микроконтроллеров, подготовить инструменты

# Задачи

Студенты должны научиться подготавливать своё рабочее место для программирования микроконтроллеров, а именно:
- установка SDK
- установка тулчейна
- установка системы сборки
- установка и настройка системы контроля версий
- создание и версионирование проектов

Познакомить студентов с аппаратной частью курса: Raspberry Pico и микроконтроллером RP2040

Студенты должны научиться записывать программу микроконтроллера в Raspberry Pico

Студенты должны познакомиться с концепцией ВПО и научиться создавать с нуля и собирать проект ВПО для Raspberry Pi Pico.

Во время первого модуля студенты должны закрепить навыки разработки, сборки и переноса в память микроконтроллера проекта ВПО.

Построить понятийный мост между общими знаниями студента про ПК из курсов информатики к микроконтроллерам.
