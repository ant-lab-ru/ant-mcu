# Результат

- [ ] В API прошивки добавлена команда `disp_text`
- [ ] Для командs реализован колбэки
- [ ] По команде из терминала пользователь может отобразить на экране текст заданного цвета с заданным цветом фона

> [!EXAMPLE] Пример
> 
> **Фигуры на экране**
> 
> ![[disp-text.jpeg]]
> 

1. Добавить в API команду `disp_text`

2. Реализовать колбэк команды

> [!HINT] Совет
> 
> Функция отрисовки строки текста реализована в библиотеке в файле `ili9341-font.c`. Чтобы использовать эту функцию в колбэке нужно включить заголовочный файл с описанием нужной функции в `main.c`.
> 

3. Скомпилировать прошивку, загрузить в RP2040, проверить, что пользователь может отобразить на экране текст заданного цвета с заданным цветом фона
