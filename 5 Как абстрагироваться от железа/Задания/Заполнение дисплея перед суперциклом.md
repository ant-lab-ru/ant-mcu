# Инструкция

> [!INFO] Справка
> Чтобы проверить работоспособность дисплея, сразу при старте прошивки нарисуем разные элементы на дисплее. Заодно познакомимся c API драйвера дисплея

1. В конце инициализации заполнить весь дисплей черным фоном и добавить после этого стартовую задержку:

``` c
ili9341_fill_screen(&ili9341_display, COLOR_BLACK);
sleep_ms(300);
```

2. В конце инициализации нарисовать три разноцветных прямоугольника:

``` c
/* 2. Coloured rectangles */
ili9341_draw_filled_rect(&ili9341_display, 10, 10, 100, 60, COLOR_RED);
ili9341_draw_filled_rect(&ili9341_display, 120, 10, 100, 60, COLOR_GREEN);
ili9341_draw_filled_rect(&ili9341_display, 230, 10, 80, 60, COLOR_BLUE);
```

3. В конце инициализации нарисовать прямоугольник без заливки:

``` c
/* 3. Hollow rectangle outline */
ili9341_draw_rect(&ili9341_display, 10, 90, 300, 80, COLOR_WHITE);
```

4. В конце инициализации нарисовать две диагональные линии:

``` c
/* 4. Diagonal lines */
ili9341_draw_line(&ili9341_display, 0, 0, 319, 239, COLOR_YELLOW);
ili9341_draw_line(&ili9341_display, 319, 0, 0, 239, COLOR_CYAN);
```

5. В конце инициализации нарисовать текст:

``` c
ili9341_draw_text(&ili9341_display, 20, 100, "Hello, ILI9341!", &jetbrains_font, COLOR_WHITE, COLOR_BLACK);
```

6. В конце инициализации нарисовать текст желтого цвета:

``` c
ili9341_draw_text(&ili9341_display, 20, 116, "RP2040 / Pico SDK", &jetbrains_font, COLOR_YELLOW, COLOR_BLACK);
```

7. Скомпилировать прошивку, загрузить в RP2040, проверить, что при включении устройства на дисплее появляются все рисунки:
