# Результат

- [ ] В API прошивки добавлены команда `disp_line`, `disp_rect`, `disp_frect`
- [ ] Для команд реализованы колбэки
- [ ] По командам из терминала пользователь может рисовать линии, прямоугольники и заполненные прямоугольники разными цветами

> [!EXAMPLE] Пример
> 
> **Фигуры на экране**
> 
> ![[disp-fig.jpeg]]
> 

1. Добавить в API команды `disp_line`, `disp_rect`, `disp_frect`

2. Реализовать колбэки команд

> [!HINT] Совет
> 
> Выбирайте аргументы команд так, чтобы они совпадали с аргументами функций рисования фигур из предоставленной библиотеки. Это сделает код понятнее и снизит вероятность ошибок.

3. Скомпилировать прошивку, загрузить в RP2040, проверить, что пользователь может рисовать на экране цветные линии и прямоугольники
